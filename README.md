MyFirstVr2 – Experiencia VR de Playa

Descripción del proyecto

MyFirstVr2 es un proyecto de realidad virtual desarrollado en Unity que permite al usuario explorar e interactuar con un entorno virtual inspirado en una playa. El proyecto busca ofrecer una experiencia inmersiva mediante el uso de Meta Quest y seguimiento de manos (Hand Tracking).

Tecnologías utilizadas

Unity

C#

sketchfab

Meta Quest

Oculus Interaction SDK

Hand Tracking

Mecánicas principales

Exploración: el usuario puede observar y recorrer el entorno virtual de la playa.

Interacción con las manos: permite utilizar las manos para interactuar con objetos del escenario.

Agarre de objetos: el usuario puede sujetar y manipular objetos interactivos, como una pala.

Inmersión en realidad virtual: permite experimentar el entorno utilizando un visor Meta Quest.

Instrucciones para abrir y ejecutar

Descargar o clonar el repositorio.

Abrir Unity Hub.

Seleccionar la opción Add Project from Disk.

Elegir la carpeta del proyecto MyFirstVr2.

Abrir el proyecto con la versión de Unity compatible.

Conectar el visor Meta Quest.

Verificar que el seguimiento de manos esté habilitado.

Abrir la escena que se llame "final"

Presionar Play para ejecutar el proyecto desde Unity o compilarlo para el visor.
